# Apps Verification

## Verify Against The Touched Operation

- creation/update/delete: verify the exact lifecycle mutation or command touched
- install or manifest changes: verify fetch-manifest, install, and install-task paths as needed
- token changes: verify the token operation touched
- dashboard touchpoints: verify the exact app-management screen or iframe route touched

## Verification Rule

Keep evidence gaps explicit instead of filling missing lifecycle steps with assumptions.
