# Dashboard Boundaries

## In Scope

- work under `sawa-dashboard/src/`
- React UI behavior and feature modules
- generated dashboard GraphQL artifacts and client usage
- dashboard tests and dashboard extension screens already present in the codebase

## Out Of Scope

- Django models and migrations
- Celery and worker behavior
- inventing extension or app build workflows not confirmed by local evidence

## Escalate To Other Skills

- use `backend-development` when the owning change is backend-first
- use `extensions-development` when the task is primarily about extension surfaces
- use `apps-development` when the task is primarily about app lifecycle and app domain behavior
