# Evaluation Notes

## Core Evaluation Model

- compare with-skill behavior against a weaker baseline or older version
- use realistic prompts and optional input files
- add concrete assertions only after observing actual output shape
- judge with evidence, not vague approval

## Local Implications

- keep root skills narrow enough that their effect is isolatable
- keep open gaps explicit so failures can be attributed to missing evidence instead of hidden assumptions
