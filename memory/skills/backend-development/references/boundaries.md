# Backend Boundaries

## In Scope

- work under `sawa-backend/saleor/`
- backend GraphQL schema, resolvers, dataloaders, and mutations
- backend tests, migration flows, transactions, locking, and concurrency-sensitive logic
- backend app infrastructure when the change is still backend-owned

## Out Of Scope

- frontend routing or component decisions
- UI styling and dashboard-only behavior
- inventing extension or app authoring workflows beyond confirmed backend evidence

## Escalate To Other Skills

- use `dashboard-development` when the work is frontend-owned
- use `extensions-development` when the task is mainly about extension surfaces
- use `apps-development` when the task is specifically about app lifecycle flows
