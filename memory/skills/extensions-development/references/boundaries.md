# Extensions Boundaries

## In Scope

- dashboard extension discovery, installation, editing, widgets, and installed-extension flows already present in the codebase
- manifest-backed extension handling in backend app infrastructure
- GraphQL exposure of `appExtensions` and `appExtension`

## Out Of Scope

- assuming a full standalone extension-authoring lifecycle not confirmed by local evidence
- treating extension work as equivalent to all app-building work
- inventing packaging or deployment workflows without local proof

## Escalate To Other Skills

- use `dashboard-development` when the change is general dashboard UI work
- use `backend-development` when the change is backend-owned and not primarily extension-scoped
- use `apps-development` when the task is about broader app lifecycle behavior
